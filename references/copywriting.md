忌：犹豫（券要过期）/ 空腹看菜单 / 独食（分享加倍）/ 忘了积分 / 原价购买（有券不用）

## 社交分享文案模板

```
🍟 今日麦门日报 {date}

{运势一句话}

👉 {今日最佳羊毛，如"龙焰鸡腿堡三件套 26.9 起"}
🎫 卡包还有 {n} 张券，{临期提醒，如"2 张今晚过期"}

{一句话收尾，如"麦门！"}

#麦门 #麦当劳 #麦麦日报
```

## 文案风格守则

- 短、梗密、口语化，像麦门信徒的日常碎碎念
- 可以玩梗但不要低俗；不贬损其他品牌
- 真实数据优先：羊毛信息必须来自 MCP 实时数据，禁止编造价格和活动
- 免责暗示：娱乐内容（运势）与真实信息（券/活动）在海报上视觉分区，避免误导
